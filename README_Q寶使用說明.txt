🐶 Q寶筆記神器使用說明

📌 功能簡介：
這是一款全自動會議錄音處理工具，內建語音辨識、說話人分離、GPT 摘要與報告輸出。
適合用於長時間會議（支援 3 小時）、逐字稿整理、主管快速閱讀摘要。

🎬 使用步驟：
1. 雙擊「Q寶筆記神器.exe」啟動程式
2. 點選「選擇音檔」，支援 .mp3、.wav、.m4a 等格式
3. 第一次使用請輸入你的 OpenAI GPT API 金鑰（config.json 或程式內提示）
4. 點選「開始處理」
5. 程式會自動進行 WhisperX 處理與 GPT 摘要整理
6. 報告將自動儲存於「outputs/」資料夾，格式為 .docx

📝 輸出內容包含：
- 🗣️ 逐字稿（含說話人與時間戳）
- 📋 條列式會議重點（GPT 自動生成）
- 🧠 總結摘要
- 🐾 Q寶風格封面（插圖 + 標語）

💡 WhisperX 注意事項：
- 建議音檔不超過 3 小時，否則會自動分段處理
- 須事先安裝 WhisperX（請參考 GitHub 官方說明）

💡 GPT 金鑰使用提醒：
- 使用 GPT-4 模型，每 1000 字約花費 NT$0.4～1
- 請確認金鑰有效，費用將由 OpenAI 向你帳戶計費
